# ReduzAlimentos

### Sistema de Gestão de Risco de Desperdício Alimentar

O ReduzAlimentos é um sistema desenvolvido em Python com o objetivo de auxiliar no monitoramento e na redução do desperdício alimentar.

A aplicação permite registrar alimentos, acompanhar quantidades utilizadas e descartadas, identificar os principais motivos de descarte e gerar informações que auxiliam na tomada de decisões.

### Funcionalidades

- Cadastro de alimentos e registros de descarte.
- Cálculo automático da taxa de desperdício.
- Monitoramento das perdas alimentares.
- Identificação dos alimentos com maiores descartes.
- Análise dos motivos de desperdício.
- Recomendações de prevenção.
- Definição e acompanhamento de metas.
- Histórico e exportação de registros em CSV.

### Tecnologias utilizadas

- Python
- Streamlit
- Pandas

### Objetivo

Contribuir para a identificação de perdas, o planejamento do uso dos alimentos e a adoção de medidas para reduzir o desperdício alimentar.
